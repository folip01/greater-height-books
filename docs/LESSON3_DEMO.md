# Lesson 3 submission recording

Record one continuous video showing both the desktop browser and a physical Android phone. Install the signed APK first, then start recording.

1. On the website, sign in with a Google account that has not previously used this shop. Show the signed-in account page.
2. Add one book on the website and show it in the website cart.
3. On the physical phone, launch the Greater Height Books APK. Sign in with the **same** Google account and open its cart. Show the first book.
4. Add a different book inside the Android app and show its cart.
5. Return to the website cart and show both books. If the desktop cart was in a background tab, bring it forward so it refreshes.

Keep the website URL, phone app, account identity, and cart contents readable. Do not reveal Google passwords, private keys, or payment details in the recording. Upload the recording to an accessible file-sharing service and test the viewer link in a signed-out browser before submitting.
